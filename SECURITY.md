# Security

## Reporting a vulnerability

Please do not report security problems in a public issue.

Report them privately through GitHub's [vulnerability report form](https://github.com/dmuhs/py-euvd/security/advisories/new).

## Supported versions

Only the latest release receives security fixes.

## Scope

This policy covers the py-euvd library. Problems with the vulnerability data or the EUVD website belong to [ENISA](https://euvd.enisa.europa.eu).
